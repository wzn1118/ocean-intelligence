## 实际使用的渲染器

- 优先尝试现有 Chromium 152.0.7977.64 snap；浏览器启动报 `Failed to create socket directory` / `Failed to create a ProcessSingleton`，退出码 21，未产生浏览器截图。直接运行 snap 内部二进制另报缺少 `GLIBC_2.38`。这些尝试不算浏览器视觉验证。
- 改用系统**已安装**的标准 SVG 渲染库：`librsvg-2.so.2`，包版本 `2.52.5+dfsg-3ubuntu0.2`；Cairo 包版本 `1.16.0-5ubuntu2.1`。未安装任何依赖。
- 通过 Python `ctypes` 调用 `rsvg_handle_new_from_file` 直接读取原 SVG，再调用 `rsvg_handle_render_document` 实际光栅化。Python 仅绑定标准库 API，没有自行解释或重画 SVG，也没有注入 CSS、替换字形或重写文件。
- CSS 单位解析 DPI 设为 96；使用完整 `(0, 0, 1200, 675)` 输出 viewport、同长宽比的 Cairo ARGB32 画布、白色查看背景，最后由 `cairo_surface_write_to_png` 导出。没有选择局部区域、修改 viewBox、平移内容或为缺失文字补画。
- 三次 `rsvg_handle_render_document` 均返回成功，Cairo 状态均为 0。**返回成功只证明渲染执行成功**，具体缺陷由下述逐图目视记录判断。
